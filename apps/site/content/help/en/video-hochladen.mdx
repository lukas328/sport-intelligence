How your match video gets into the app.

## Uploading

Open the match under "Matches" and choose "Upload video". Use the file as the phone saved it.

- **Interrupted?** Choose the same file again. The upload continues where it stopped.
- **Mobile data:** Large files are best uploaded on Wi-Fi. The app warns you.
- **One file:** {MULTI_FILE ? "Best is the whole match in one file (MP4, MOV or MKV). If you have several files, such as one per half, upload them all to the same match; all of them are analysed." : "Best is the whole match in one file (MP4, MOV or MKV). A second file, such as the second half, is stored and can be played, but only the first file is analysed."}
- **By link:** A direct link to a video file works too, for example the download link from Veo or Spiideo.

## After uploading

The analysis starts by itself. You see which step is running, and you get an e-mail when the three things are ready. If an analysis fails, it does not count, and the app tells you what you can do.

## Match report

If there is a match report (for example from the federation), the app takes the goals, the scorers and the penalties from it. Then the result and the course of the match are right, even without video.

## How long videos are kept

The original video is deleted after 90 days. A smaller version for the scenes stays. You get a message seven days before.

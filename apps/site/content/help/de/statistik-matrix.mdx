Die Statistik-Matrix ist ein Baukasten für eigene Auswertungen.

## Aufbau

- **Zeilen:** Spieler (Nummer), Position, Spielzug, Spiel, Gegner, Halbzeit, Spielphase in 10-Minuten-Abschnitten, Wurfzone oder Wurfart.
- **Spalten:** bis zu acht Kennzahlen, zum Beispiel Tore, Wurfquote, Paraden, Ballverluste oder xG.
- **Filter:** Team (wir oder Gegner), letzte Spiele, Halbzeit.

Ein Klick auf eine Zelle zeigt die Szenen dahinter, sofern die Ereignisse eine Videozeit haben.

## Vorlagen

Speichere eine Zusammenstellung als Vorlage, zum Beispiel «Werfer pro Halbzeit». Vorlagen gelten für das ganze Team.

## Export

Die Matrix lässt sich als CSV oder Excel herunterladen. Unter «Daten austauschen» im Menü «…» des Spiels gibt es zusätzlich den Export als Sportscode-XML und als CSV aller Ereignisse sowie den Import von Sportscode-XML: Jede Instanz wird ein Clip, Code und Labels werden eigene Tags. Importierte Tags verändern keine Kennzahlen.

La Matrice statistique est une boîte à outils pour tes propres analyses.

## Structure

- **Lignes :** joueur (numéro), poste, combinaison, match, adversaire, mi-temps, phase de jeu par tranches de 10 minutes, zone de tir ou type de tir.
- **Colonnes :** jusqu'à huit chiffres clés, par exemple buts, réussite au tir, arrêts, pertes de balle ou xG.
- **Filtres :** équipe (nous ou l'adversaire), derniers matchs, mi-temps.

Un clic sur une cellule affiche les scènes correspondantes, si les événements ont un temps vidéo.

## Modèles

Enregistre une configuration comme modèle, par exemple « Tireurs par mi-temps ». Les modèles valent pour toute l'équipe.

## Export

La matrice peut être téléchargée en CSV ou en Excel. Sous « Échanger des données » dans le menu « … » du match, tu trouves en plus l'export en XML Sportscode et en CSV de tous les événements, ainsi que l'import de XML Sportscode : chaque instance devient un clip, le code et les labels deviennent des tags distincts. Les tags importés ne modifient aucun chiffre clé.

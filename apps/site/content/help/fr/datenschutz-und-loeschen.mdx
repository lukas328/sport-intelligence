Les vidéos et les données appartiennent à ton club.

## Où se trouvent les données

Prévu : l'app et sa base de données tournent sur des serveurs en Suisse, les vidéos sont stockées dans un espace de stockage dans l'UE. Nous nommons les fournisseurs avant le lancement dans la [déclaration de protection des données](../datenschutz). La loi suisse sur la protection des données s'applique et, si nécessaire, le RGPD.

## Qui voit quoi

Seul le staff de l'équipe voit la vidéo. Les autres ne voient que ce que vous partagez avec un lien. Les liens partagés expirent et peuvent être bloqués à tout moment.

## Télécharger les données

Dans ton compte, sous « Mes données », tu télécharges toutes les données enregistrées à ton sujet.

## Supprimer le compte

Ton compte, tes connexions et tes affiliations sont supprimés. Les notes que tu as partagées restent, sans nom.

## Supprimer le club

Les admins du club peuvent supprimer tout le club : toutes les équipes, tous les matchs, toutes les vidéos et toutes les données. C'est définitif.

## Vidéos

Les vidéos originales sont supprimées après 90 jours. Une version plus légère pour les scènes reste jusqu'à ce que tu la supprimes ou que tu supprimes le match.

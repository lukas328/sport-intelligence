Chaque personne du club a un rôle par équipe. Le rôle détermine ce qu'elle peut voir et modifier.

| Rôle | Ce qu'il permet |
| --- | --- |
| Admin du club | Gérer le club, l'abonnement, les équipes et les membres |
| Entraîneur·e | Modifier les matchs, les vidéos, les événements, les présentations et les combinaisons |
| Analyste | comme Entraîneur·e, sans la gestion de l'équipe |
| Entraîneur·e des gardiens, Préparateur·rice physique | Lire les analyses, séquences et commentaires pour son domaine |
| Team manager | Organiser les matchs et l'effectif, pas de travail d'analyse |
| Joueur·euse, Gardien·ne | Ses propres séquences, tâches et contenus partagés |
| Parent | Uniquement les contenus de son propre enfant et ses consentements |
| Invité·e | Uniquement lire les contenus partagés |

## Changer de rôle

Les admins du club modifient les rôles dans les paramètres sous « Membres ». Les invitations contiennent déjà le rôle ; il peut être adapté par la suite.

## Transmettre l'administration

Qui quitte la gestion du club transfère le rôle d'admin à une autre personne. Un club a toujours au moins un admin.

## Connexion à deux facteurs

Pour les admins et le staff, nous recommandons la connexion avec une application d'authentification. Conserve les codes de récupération en lieu sûr.

## Measurements (synthetic, full pipeline: rendering, detection, tracking, teams)
`docs/perf/events-eval.md`, two synthetic matches of 200 s with scripted goals, throw-offs and a
side change:

| event | precision | recall |
|---|---|---|
| throw-offs | 1.00 / 1.00 | 1.00 / 0.86 |
| goals | 1.00 / 1.00 | 0.83 / 0.67 |
| possession changes | 1.00 / 1.00 | 1.00 / 1.00 |
| side change | 1.00 / 1.00 | 1.00 / 1.00 |

One goal per match is right before half-time and cannot be inferred by design. Seed 11 misses the
goal recall target (0.67 vs 0.7); I did not tune the detector to the test. On exact positions all
throw-offs and possession changes are found. Real-footage numbers: pending (Q-ADD-8).

Not yet measurable: spotlight on the right player in 95 % of frames, portrait crop without cut-off
main actors in 90 % (both need the golden set with real matches).

## Video material
I looked for openly licensed handball footage. TeamTrack (handball full-pitch, tracking labels) and
the UWB amateur positions dataset (CC BY 4.0) fit well, but their hosts (Kaggle, Google Drive,
Zenodo) are blocked by this environment's network policy. YouTube videos are not downloaded (terms of
use, ADR 018).

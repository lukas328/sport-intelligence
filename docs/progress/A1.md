## Deviations from ADR 017 (deliberate)
- `ClipTag` links clips only; tagging events and plays follows in A2 with the tag UI if needed.
- Match type `training` (4.8) is not added yet: it needs matches without opponent; moved to A2.
- A team default format is derived from `is_youth`; a stored per-team default follows with the
  team settings in A2.
- Club-defined formats live in `match_formats`; the API currently offers the built-in templates plus
  custom values per match. Selecting a club format: A2.

## Privacy review (4.9 acceptance)
- Parents see only their own children (guardianship rows, RLS per club); the API checks the relation on
  every consent call; team endpoints stay closed for the role.
- The personal data export now lists the children linked to the account.
- Consent changes are audit-logged (`consent.given_online`, `consent.revoked_online`) with purpose and
  giver, not with free text.
- Minors: age from the birth year is treated conservatively (18 in the calendar year counts as minor);
  unknown age in a youth team counts as minor.
- Opponent names only with a stated public source; never in share links or exports (the shot export uses
  numbers only).
- Open point: when a child turns 18, the guardianship stays but the player decides; a reminder to hand
  over consents is listed in OPEN_QUESTIONS (Q-ADD-7).

## What was built
**Backend**: opponents, matches (kit colours, result, half-time, status, demo flag), video assets per camera
(main, goal cams), processing jobs with stages, clips, playlists (ordering, sharing with players),
time-stamped comments, drawings (normalised shapes). Migration 0004 with RLS. New permissions in the policy
table (`match.*`, `video.upload`, `clip.write`, `playlist.*`, `comment.*`, `annotation.write`); the matrix test now
covers **38 endpoints × 7 roles**. Deleting a match removes all stored objects (audited count).
Upload/import/ingest flow (ADR 011), internal job callbacks, Server-Sent Events, authorised HLS delivery.

**Worker**: ingest with real ffmpeg (HLS ladder, proxy 1280 px / 25 fps, poster, sprite + WebVTT), heuristic
quality check (resolution, frame rate, length, exposure, 50 Hz flicker, camera motion, sharpness; court
visibility marked "not evaluated" until the court model in M3), link import with SSRF checks.

**Web**: team tabs (matches, roster, playlists), match list and creation, match page with drag-and-drop
upload (camera choice, pause, resume, leave warning), live processing stages, quality report with filming tips,
analysis workspace: HLS player with timeline markers, thumbnail previews on hover, frame stepping, speed,
keyboard shortcuts (space, arrows, `,` `.`, `[` `]`, I/O, D, F), comments, clips (I/O marks, straight into a
playlist), drawing tools (arrow, line, circle, freehand, spotlight, colours) shown at their time, playlists page
playing clips in sequence across matches.

## Tests
- Python: 121 tests, coverage 93 %, incl. upload/resume/complete, job callbacks, media access control, link
  import validation, clips/playlists/comments/drawings permissions, ffmpeg ingest end to end on a generated
  video, quality heuristics on synthetic frames, import redirects to private addresses.
- Vitest: 26 (upload manager, formatters, VTT parsing, CSP, i18n keys).
- Playwright: 18 (new: full match flow with real upload, pause/resume, processing, playback, keyboard, comment,
  clip, drawing, axe checks; playlist creation and sharing).

## Decisions
ADR 011 (direct multipart, HLS fMP4 via API with access control, static ffmpeg). SeaweedFS needed a higher
volume limit locally. CSP moved into middleware so the storage origin is configurable at runtime.

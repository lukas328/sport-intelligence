# M4 Events and match report: report

Date: 2026-11-03 · Status: **done for the manual and import path, automatic event detection open** (continuing with M5)

## Acceptance criteria
| Criterion | Result |
|---|---|
| Events with source, confidence and correction history | ✅ `events` table with `source` (`user_correction`, `official_feed`, `paper_report`, `heuristic`, `model`), confidence, `corrections` rows for every create/update/delete |
| Match clock from video time and back | ✅ kickoff marks per half (`PUT /matches/{id}/kickoff`), events without video time (feed, paper) are aligned when a kickoff is set |
| `packages/metrics` with definitions | ✅ `handball_metrics` (stats, situations, xG prior), `packages/metrics/DEFINITIONS.md`, zones shared between Python and TS with common test vectors |
| Analysis screen: overview, match report, shots, every number clickable | ✅ tabs Video / Übersicht / Matchreport / Würfe; every count opens its events, every event jumps into the video 4 s before the action |
| Official feed adapter | ✅ CSV (`period;clock;team;event;number`, German aliases) and JSON upload; no scraping |
| Paper report importer | ✅ JSON per `docs/schemas/paper-report.schema.json` (assumed format, Q-DATA-2), match without video, warnings for score mismatches and unknown numbers, names from the sheet kept |
| Automatic events (pose, shot heuristic, throw-off, scoreboard OCR, final-score constraint) | ✗ open: need trained pose/ball models and real footage (Q-ML-2, Q-DATA-1). The `heuristic`/`model` sources and confidence handling are in place so automatic events plug in without schema changes |
| Possessions/phases baseline | ◐ possessions are estimated from shots and turnovers (labelled "geschätzt"); phases from tracking follow with real footage |

## What was built
- API: migrations 0006/0007 (events, possessions, corrections, stats cache, kickoff marks, report extras),
  routers for events, stats (cached by an event version hash), kickoff, feed import, paper reports; policy
  matrix extended (staff write, players read).
- Web: event tagger next to the video (team toggle, roster player or opponent number, outcome buttons,
  hotkeys G/S/M/P/T, 7 m and fast-break flags, turnover type, click-to-place shot position, goal-zone pick,
  kickoff buttons, feed upload), analysis tabs with score progression, comparison table, per-player match
  report incl. turnover types and opponent numbers, shot map + goal grid with shooter/keeper view.
- Paper report import on the team match list.

## Tests
- Python: metrics package, zones (shared vectors), events API (CRUD, filters, corrections, cache, kickoff
  mapping, feed import, paper import). 162 tests, coverage 93.7 %.
- Vitest: zones parity in TS.
- Playwright: tagging in the video (kickoff, hotkey goal, miss), overview counts, number → event list →
  playback jump; paper report import → overview → match report → shots, with axe checks on each view.

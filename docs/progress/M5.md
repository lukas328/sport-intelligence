|---|---|

## Tests
- Vision: physical (constant speed, noise rejection, sprints, gaps/jumps, merge), identity (constraints,
  conflicts), audio offset (synthetic impulses with noise, flat noise has low confidence).
- GPU worker: sync job end to end with WAV files, failure reporting; analysis summary has physical load.
- Worker: ingest writes the sync audio.
- API: identities (roster check, carry-over on re-run, clearing), physical aggregation, sync start on either
  upload order, low/high confidence, manual offset; policy matrix with events, stats, kickoff, physical.
- Metrics: goalkeeper block incl. GSAx.
- Playwright: Torhüter tab after a paper import, Laufleistung tab with heatmap after analysis.
- Python: 177 tests, coverage 93.7 %.

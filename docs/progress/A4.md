## Demo analysis
The demo is a **fictional match** ("HC Beispiel" against "TV Muster"): events are drawn from a seeded
random generator, the figures are computed with `handball_metrics`, the same code as in the app. The
page says so above the analysis, and there is no video (we have no licensed match video to show).
Interactive: filters for team, outcome and half, shot map on the shared court geometry (keyboard
operable), key figures with xG marked as estimate, score timeline.

## Usability test script (for staging)
Three coaches without prior knowledge, 45 minutes each, think aloud, no help from us:
1. Register the club and a team from the marketing site (language kept).
2. Import the roster from a CSV and invite an assistant coach.
3. Create a match and upload a video; find the analysis when it is done.
4. Correct one automatic event and tag a shot.
5. Build a presentation with three clips and a drawing, present it with the phone as remote.
6. Find out how the annual invoice works (help centre only).
Pass: every task done without help by at least two of three; findings go into OPEN_QUESTIONS.

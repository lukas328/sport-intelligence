# Runde 2: zwei Richtungen aus dem Sport selbst

Stand: 10. November 2026. Die ersten fünf Richtungen (Konsole, Trikot, Piktogramm, Kassette, Halle)
kamen aus Gegenständen. Diese zwei kommen aus der Energie des Spiels.

| Ordner | Leitidee |
|---|---|
| `sendung/` | Dein Spiel geht auf Sendung: die Sprache der Sportübertragung, dein Verein ist der Sender. |
| `wurf/` | Handball ist Tempo im Flug: alles lehnt nach vorn, was zählt, fliegt als Bahn ins Ziel. |

Jeder Ordner hat `index.html` (im Browser öffnen, Vereinsfarbe oben rechts umschalten), `README.md`
und `shots/` mit den sechs Ansichten und `bogen.jpg` als Übersicht.

Bilder neu erzeugen: `node docs/design/ux-reset/runde2/shots.js <sendung|wurf> [rot|blau|gelb|schwarz] [Skala]`.
Das Skript meldet auch Elemente, die aus einem Rahmen ragen.
